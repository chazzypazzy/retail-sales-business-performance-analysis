# Data folder

The original row-level invoice dataset was not included with the supplied files. Place it here only if you have the source file and permission to publish it.

Recommended filename: `retail_invoice_data.csv`

Before publishing, check for:
- customer names, emails, phone numbers, addresses, and other personal identifiers;
- confidential business information;
- licensing or redistribution restrictions;
- consistent date, currency, quantity, discount, return, and cancellation formats.

`project_metrics.csv` contains presentation-level summary metrics only. It is not transaction-level data and cannot reproduce the report by itself.
